# Exemplara editing

An editing session holds a document and its authoring context independently of its presentation.

## Language

**Editor session**:
The ongoing editing context for one document, including its history, selection, and authoring preferences. It can continue while no editor view is attached.

**Editor view**:
An attached presentation of an editor session through which an author interacts with the document.

**Portable plugin**:
An editor feature whose behavior belongs to the session and remains available without an attached view.

**Legacy view extension**:
An editor feature whose behavior is supplied by an attached view and remains available for that attachment's lifetime.
